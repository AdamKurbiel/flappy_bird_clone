# flappy bird clone

Flappy bird clone written in javascript (canvas API).
Use your left mouse button to jump, and avoid obstacles.

## features
- Saves up to 3 highscores via cookies
- You can restart the game after you loose
- Game physics similar to original flappy bird

## installation
You can access the game through [github pages](https://adamkurbiel.github.io/flappy_bird_clone).
Although You can host it on Your own:
```bash
git clone https://github.com/adamkurbiel/flappy_bird_clone.git
cd flappy_bird_clone
```
then open up a live server!
